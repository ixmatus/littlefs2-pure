# Architecture decision records

Each significant decision lands here as a numbered, named markdown file. The format follows the template at `template.md`: context, decision, consequences, related.

The first ADR is `0001-pure-rust-no-ffi.md`. Increment monotonically.

ADRs record *why*, not *what*. The code records what. When an ADR's claim becomes stale or wrong, mark it superseded and write a new one rather than editing the old one in place: the history matters.
